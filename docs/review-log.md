# 评审记录（review-log）

每完成一个任务追加一条。规则：

- 只记录真实发生的事：哪个测试或检查失败、失败信息是什么、怎么修的。
- "测试先红"指先运行测试并确认它因为功能缺失而失败，再写实现。红的输出摘要如实摘录。
- 没有发现问题就写"无"，不编造。
- 代码与本记录都由 AI 助手（Claude）在人类给定的任务与验收标准下产出；"发现的问题"里的"模型"即该助手。
