每一条都写明"期望行为"和"由哪个任务的测试覆盖"。期望行为以 `docs/tasks.md` 中的假设编号（A1…A12）为依据。

|---|---|---|---|
| 1 | 同一文件内重复 `id` | 输入错误，退出码 2，信息含两处行号（A5） | 2 |
| 2 | 金额为空字符串或只有空白 | 输入错误，带文件与行号（A4） | 2 |
| 3 | 金额非法（`abc`、`1,000.00`、`$5`、`1e3`、`NaN`、`Infinity`） | 输入错误（A3）。特别注意 `Decimal` 本身会接受 `NaN`、`Infinity`、`1e3`，必须显式拒绝 | 2 |

## 已知不覆盖（写明比假装覆盖更诚实）

- 超出内存的文件：`id -> 金额` 全量放内存，不在范围内。
- 一个 id 对应多币种或多条流水的"一对多对账"：不支持，重复 id 直接报错（A5）。
- 非 UTF-8 编码（GBK、UTF-16 等）：明确拒绝，不做转换。
- 金额的货币符号、千分位、科学计数法：明确拒绝（A3）。
